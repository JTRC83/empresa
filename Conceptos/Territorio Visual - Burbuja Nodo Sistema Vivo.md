# Territorio Visual - Burbuja Nodo Sistema Vivo

Metáfora visual principal validada en la actualización de marca. Representa un negocio como sistema cerrado que se organiza internamente y luego se conecta.

## Las 4 fases visuales

### Fase 1: Caos / Analógico
- Información dispersa
- Elementos sueltos
- Desorden

### Fase 2: Digitalización
- Aparece estructura
- Se agrupa la información
- Nace la "burbuja" (núcleo del negocio)

### Fase 3: Control / Sistema Operativo
- Capas organizadas
- Flujo interno
- Todo conectado dentro del sistema
- Aquí nace [[Naming - SOM OS|SOM-U]]

### Fase 4: Expansión / Conexión externa
- El sistema se conecta con otros
- Redes entre "burbujas"
- IA como capa invisible que potencia conexiones

## Resumen clave

> De caos → a sistema → a red inteligente

## Alternativas visuales alineadas

- Nodo
- Núcleo
- Célula
- Sistema orbital
- Red modular

Todas deben transmitir: **unidad + estructura + expansión**
