# Arquetipo de Marca - El Arquitecto

Arquetipo creativo definido durante el [[Metodología - Proceso creativo 7 días|proceso creativo de 7 días]].

## Esencia

Alguien que observa el caos del cliente y construye una estructura sólida (los "raíles") para que el negocio pueda circular con seguridad.

## Atributos

- **Estructural**: todo debe tener un orden para ser reutilizable y escalable
- **Transparente**: sin agendas ocultas, comunicación directa y clara
- **Observador / Empático**: entiende el contexto y el detalle del cliente

## Contrapunto narrativo

El Arquitecto se opone al **Reparatodo** (etapa anterior de Adrián):
- El Reparatodo trabaja para otros bajo esquemas ajenos
- El Arquitecto crea desde cero con metodología propia
- El Reparatodo apaga fuegos; el Arquitecto construye raíles

## Manifestación visual

- Estilo visual: limpio, modular, por capas
- Tono comunicativo: seguro pero humano, directo pero cercano
- Personalidad: Observador, Estratégico, Empático
