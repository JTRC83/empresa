# Producto - App central + módulos

Descripción del producto/servicio core de SOM-U: una aplicación central que actúa como núcleo del ecosistema digital del negocio.

## Estructura

### App central del negocio
Actúa como núcleo del ecosistema digital. A partir de ahí se integran diferentes módulos según las necesidades del proyecto.

### Módulos disponibles

- App web de gestión interna
- Web corporativa
- CMS y gestión de contenido
- Chatbots
- Automatizaciones internas
- Newsletter
- Ecommerce
- SEO / GEO / AEO básico
- Sistemas de generación de contenido
- Presencialidad online

## Principio de diseño

> Cada proyecto se construye por módulos, no como un pack cerrado.

Esto permite:
- Escalabilidad progresiva
- Reutilización de componentes
- Adaptación a las necesidades reales del negocio
- Evitar la "intoxicación de herramientas"
