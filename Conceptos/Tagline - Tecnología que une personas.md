# Tagline - Tecnología que une personas

Tagline validada directamente por Adrián Colom durante el proceso de feedback. Representa la versión más humana y cercana del mensaje de marca.

## Lectura estratégica

El cambio de "conectar" a "unir" es muy relevante:
- **Conectar** → interacción puntual
- **Unir** → estructura, sistema, comunidad

Este ajuste alinea perfectamente con [[Naming - SOM OS|SOM-OS.dev]]: no crea conexiones aisladas, crea sistemas donde las conexiones tienen sentido.

## Implicación para el diseño

La marca NO debe representar:
- Puntos conectados sin más

La marca SÍ debe representar:
- Sistemas donde todo pertenece a algo mayor
- Unidad dentro de estructura
