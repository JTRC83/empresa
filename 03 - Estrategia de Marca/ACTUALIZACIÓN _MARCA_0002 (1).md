Versión validada por cliente  “Tecnología que une personas.”  Lectura estratégica  Este cambio es MUY relevante:  Conectar   →   interacción puntual  Unir   →   estructura, sistema, comunidad  Esto alinea perfectamente con SOM-U:  No crea conexiones aisladas  Crea sistemas donde las conexiones tienen sentido  Implicación para diseño  La marca NO debe representar:  puntos conectados sin más  Debe representar:  sistemas donde todo pertenece a algo mayor  unidad dentro de estructura  1. Traducción del feedback del cliente  Lo que Adrián describe no es un estilo, es un proceso:  Evolución de un sistema  Modelo visual conceptual  FASE 1  CAOS / ANALÓGICO  Información dispersa  Elementos sueltos  Desorden  FASE 2  DIGITALIZACIÓN  Aparece estructura  Se agrupa la información  Nace la “burbuja” (núcleo del negocio)  2. CONCEPTO VISUAL CENTRAL

FASE 3  CONTROL / SISTEMA OPERATIVO  Capas organizadas  Flujo interno  Todo conectado dentro del sistema  Aquí nace SOM-U  FASE 4  EXPANSIÓN / CONEXIÓN EXTERNA  El sistema se conecta con otros  Redes entre “burbujas”  IA como capa invisible que potencia conexiones  RESUMEN CLAVE  De caos   →   a sistema   →   a red inteligente

Concepto núcleo  La BURBUJA / NODO / SISTEMA VIVO  Qué representa  Un negocio como sistema cerrado (inicio)  Que se organiza internamente (estructura)  Y luego se conecta (expansión)  Evolución visual  1 . Elementos sueltos  2 . Se agrupan   →   forma orgánica (burbuja)  3 . Se estructuran   →   capas internas  4 . Se expanden   →   conexión con otras burbujas  Alternativas visuales alineadas  Nodo  Núcleo  Célula  Sistema orbital  Red modular  Todas deben transmitir: unidad + estructura + expansión  3.
