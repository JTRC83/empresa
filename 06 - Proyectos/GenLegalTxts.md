# GenLegalTxts

- Plataforma web para generar textos legales personalizados para sitios web
- Orientada al mercado español y cumplimiento normativo europeo
- Generadores disponibles:
  - **Aviso Legal** — para cualquier sitio web
  - **Política de Privacidad** — cumplimiento GDPR/LOPD
  - **Política de Cookies** — gestión de cookies y rastreo
  - **Condiciones Generales de Venta** — para ecommerce
  - **Declaración de Accesibilidad** — para organismos públicos
  - **Aviso de Confidencialidad** — para comunicaciones
- Flujo: elige generador → rellena formulario → copia y pega el texto legal
- Tabla de orientación por tipo de web (ecommerce, informativa, con formularios, etc.)
- URL: https://www.genlegaltxts.com/
- Parte del ecosistema SOM-U
