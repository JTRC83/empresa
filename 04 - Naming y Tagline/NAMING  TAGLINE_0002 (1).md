1. Propuestas naming base SOM. SOM-U  2.Propuestas de taglines  3.Recomendación estratégica final  4.Cierre  NAMING Y TAGLINE  ADRIAN COLOM  Concepto Central: De aislado a conectado

1. LÍNEA MINIMALISTA (FUERZA DE MARCA)  Opciones:  SOM  SOM-U  SOMU  SOM.UN  SOM.ONE  SOM.OS  Lectura estratégica:  Directo, contundente, memorable  Alta escalabilidad (marca sistema)  Muy alineado con comunidad + identidad  Recomendado si se busca una marca premium, conceptual y sólida  1. PROPUESTAS NAMING . BASE SOM/SOM-U

2. LÍNEA SISTEMA / ARQUITECTURA  Opciones:  SOM SYSTEMS  SOM-U SYSTEMS  SOM ARCHITECTURE  SOM STRUCTURE  SOM GRID  SOM NETWORK  SOM LAYER  SOM CORE  Lectura estratégica:  Refuerza el posicionamiento de arquitecto de sistemas  Más explícito en propuesta de valor  Ideal para mercado B2B  Recomendado si se quiere claridad + autoridad técnica

3. LÍNEA HUMANO + TECNOLOGÍA (TECNOLOGÍA-TIERRA)  Opciones:  SOM CONNECT  SOM FLOW  SOM LINK  SOM BRIDGE  SOM ROOTS  SOM EARTH  SOM FIELD  SOM UNION  Lectura estratégica:  Equilibrio entre emoción y tecnología  Refuerza el concepto de conexión  Más accesible para cliente no técnico  Recomendado si el foco es humanizar la tecnología

4. LÍNEA CONCEPTUAL / DIFERENCIAL  Opciones:  SOM-U  SOM TO ONE  SOM UN  SOM ALL  SOM TOT  SOM NODE  SOM GRID LAB  SOM ORIGIN  Lectura estratégica:  Naming más disruptivo  Alto potencial de storytelling  Construye universo de marca propio  Recomendado si se busca marca única y con profundidad conceptual

5. LÍNEA HÍBRIDA (PERSONAL + SISTEMA)  Para mantener vínculo con Adrián Colom:  COLOM SOM  COLOM SOM-U  SOM by COLOM  COLOM SYSTEM  COLOM NETWORK  Recomendado si se quiere reforzar marca personal + sistema escalable
